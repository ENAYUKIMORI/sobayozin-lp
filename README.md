SobaYozin 限定ベータ版 利用規約

第1条（適用）

本規約は、[雪森えな]（以下「運営者」）が提供する
SobaYozin 限定ベータ版（以下「本サービス」）の利用条件を定めるものです。

利用者は、本サービスを利用することにより、本規約に同意したものとします。

第2条（本サービスの目的）

本サービスは、利用者の考えの整理、進捗確認、相談、タスク候補の整理、
意思決定の補助等を目的とする開発中のソフトウェアです。

第3条（ベータ版）

1. 本サービスは開発中のベータ版であり、正式版と同等の品質、可用性、
   正確性、継続性を保証するものではありません。
2. 運営者は、予告なく本サービスの全部または一部を変更、中断または終了できます。
3. ベータ期間中のデータについて、恒久的な保存または将来バージョンとの互換性を保証しません。

第4条（アカウント）

1. 本サービスでは、Googleログイン等を用いて利用者を識別する場合があります。
2. 利用者は、自身のアカウントを適切に管理するものとします。
3. 他人のアカウントを無断で使用してはなりません。

第5条（AIによる出力）

1. 本サービスはAIを利用して、質問、整理、要約、提案等を行う場合があります。
2. AIによる出力は、完全性、正確性、最新性、特定目的への適合性を保証しません。
3. AI出力は利用者の判断を補助するためのものであり、最終的な意思決定は利用者が行うものとします。
4. 医療、法律、税務、投資その他専門家による判断が必要な事項について、
   本サービスの出力のみを根拠として判断しないでください。

第6条（入力内容）

1. 利用者は、自ら入力する情報について必要な権利または権限を有しているものとします。
2. 利用者は、法令、契約、守秘義務等に違反する情報を入力してはなりません。
3. 限定ベータ期間中は、秘密情報、認証情報、高度に機微な個人情報等の入力を避けてください。

第7条（禁止事項）

利用者は、以下の行為をしてはなりません。

(1) 法令または公序良俗に違反する行為
(2) 第三者の権利または利益を侵害する行為
(3) 本サービスへの不正アクセス
(4) 認証、利用制限、アクセス制御等を不正に回避する行為
(5) 本サービスまたは関連システムに過度な負荷を与える行為
(6) マルウェアその他有害なプログラムを送信する行為
(7) その他、運営者が本サービスのテスト目的に照らして不適切と判断する行為

第8条（知的財産権）

1. 本サービスを構成するプログラム、画面、デザイン、文章等に関する権利は、
   運営者または正当な権利者に帰属します。
2. 利用者が本サービスへ入力する内容について、
   利用者が保有する権利が本規約により運営者へ移転するものではありません。
3. 運営者は、本サービス提供、AI処理、不具合調査、利用制御等、
   本サービス運営に必要な範囲で入力内容を処理することがあります。

第9条（外部サービス）

本サービスでは、認証、クラウド処理、AI処理等のために、
Google、Firebase、Google Cloud、Gemini API等の外部サービスを利用する場合があります。
これらの外部サービスには各提供者の規約・ポリシーが適用される場合があります。

第10条（保証の否認）

運営者は、本サービスについて、利用者の特定の目的への適合、
中断しないこと、エラーが発生しないこと、AI出力が正確であること等を保証しません。

ただし、法令上免責が認められない事項については、この限りではありません。
